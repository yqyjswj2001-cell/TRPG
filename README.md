## 资料状态

世界文档和原始 JSON / JSONL 内容保持原样；部分文字保留旧插件术语、调用约定或伪代码，仅供理解原规则。旧概率、固定开局、数值例外及模型分工都没有在本次整理中重新定稿，也不代表当前新团必须遵守。

`rules/` 和 `reference/lexicons/` 为静态内容导出：只读取源码中的字面量及简单常量引用，没有运行原插件、生成新角色或重抽资料。姓名缓存等运行时生成结果未重建；部分派生计算不属于导出的静态表。JSON 中数值索引以字符串键保存。

仓库已移除插件程序、安装配置、模板、测试、开发工具和开发工作流。使用这些资料不需要安装 AstrBot 或 NapCat。详细来源和去向见[整理记录](reference/整理记录.md)。

目录约定：世界规则放 `world/`，内容资料放 `data/`，纯设定表放 `rules/`，创作参考放 `reference/`；根目录仅保留本说明与 `AGENTS.md`。临时文件、运行存档、日志、密码和 Token 不入库。
