## 安装方法

1. 把整个 `astrbot_plugin_template` 文件夹复制到 AstrBot 的插件目录：
   ```
   AstrBot/data/plugins/astrbot_plugin_template/
   ```
   （记得改成实际的文件夹名）
2. 重启 AstrBot，或在管理面板的「插件管理」页面点击刷新/重载。
3. 发送 `/xxx` 测试指令，确认安装成功。

## 数据保存在哪里？

全部在 AstrBot 的 `data/plugin_data/astrbot_plugin_template/` 目录下，重启不会丢失。
