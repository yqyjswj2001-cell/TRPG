# 东荒世界档案

> 本文件压缩自《东荒修仙TRPG世界运行总纲.txt》第 7 节。开团时整体加载一次
> 定基调；日常调用只按玩家当前所在区域取对应段落（下面每个区域标题就是
> 查找用的 key：`中部`/`东部`/`南部`/`北地`/`西部`），不整份塞进提示词。

## 总体格局

东荒处于动荡前夜。表层秩序尚存，深层结构正在重组。

## 中部

旧主脉衰退，灵气持续向东外流，旧权力中心仍在维持秩序。当前阶段：结构偏移。
势力初态：中部守成宗门与旧王朝——稳定，但趋向收缩或内部分化。资源初态：
中部主脉残核——紧张、波动。

## 东部

新生支脉活跃，成为资源、人口与势力扩张的新中心。当前阶段：开放重组。
势力初态：东部拓展宗门与新域统合势力——扩张，并处于合作竞争。资源初态：
东部新生支脉——活跃、波动。

## 南部

承担人口、道路、粮食、水土和物资流通，承载压力持续上升。当前阶段：压力
积累。势力初态：南部水土维护结构——稳定，但负担持续上升。资源初态：南部
资源网络——稳定、趋紧。

## 北地

表层贫瘠，深层灵气沉潜，承担封闭、缓冲和观测功能。当前阶段：常态维持。
势力初态：北地守护与观测结构——稳定并保持封闭。资源初态：北地沉潜资源——
封闭。

## 西部

断脉、旧战场、遗迹封禁和因果沉积集中，处于高压与临界失衡。当前阶段：
临界失衡。势力初态：西部封禁结构——接近崩溃。资源初态：西部遗迹与异常
资源——高压、封存。

## 主要矛盾

旧中心权利 / 新生资源控制 / 南部承载负担 / 西部历史责任 / 北地开发与封闭 /
天道局部收敛。

## 历史顺序

上古灵气格局形成 → 主灵脉成为文明中心 → 资源开采与权利冲突加深 → 灵脉
战争发生 → 人工引流与过度承载使主脉分裂 → 灵气开始向东迁移 → 天道通过
收缩和封闭阻止全面崩坏 → 遗迹进入封禁时代 → 人口与生产向南转移 → 深层
压力向北沉潜 → 西部形成因果沉积和断裂带 → 当代东部新脉形成 → 旧秩序进入
重组。

## 隐藏影响者（仅按类型存在，不直接统治）

自限于世界边缘的高阶修行者 / 历史残留形成的区域意识 / 因果异常型生命或物 /
天道边缘观测者。它们不直接统治，而通过信息、封禁、承载和延迟干预改变格局。

## 未来重大事件类型

灵脉争夺 / 遗迹联锁开启 / 势力崩解或重组 / 因果集中灾变 / 天道局部修正 /
区域结构重塑。每个未来事件必须具备：触发条件、无人干预时的自然路径、
外部干预后的变化方向。

过去历史与世界法则属于**不可逆主线**。以下内容属于**可变分支**：控制权、
责任承载、资源流向、遗迹开放顺序、势力关系、区域重组方式、终局形态。

## 终局形态

东荒终局可能表现为：重组 / 崩解 / 升格 / 分裂。玩家可以改变终局形态，
但不能删除终局的历史前提。
