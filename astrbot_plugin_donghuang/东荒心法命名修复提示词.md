# 东荒·心法功法重新命名任务

## 背景

`techniques_100k.json`（JSONL，一行一条功法）里 `category` 是"心法"的
条目，命名方式跟其它类别（拳法/刀法/剑法/腿法/身法）用的是**同一套"动词
+名词+后缀"模板**，完全没有体现心法本身的特殊性。比如黄级心法抽到的
"甩烟诀"，"甩"是一个明显的肢体动作词，读起来更像一门身法或拳脚招式，
不像一门心法。

问题集中在两个品阶：
- **黄级心法**：约 13031 条，命名几乎全是"动作动词+具体名词+经/诀/功"
  这种组合（比如"撕金经""扣幽诀""挖虚功""挂树诀""扫锡功""踏丘经"
  "运日诀""挂铁诀""抛空诀""掘雨诀""拖影功""铲猫经"），"撕""扣""挖"
  "挂""扫""踏""挂""抛""掘""拖""铲"这些字全是手上/脚上的具体动作，
  完全没有"意识""灵气""运转"这类心法该有的抽象感。
- **玄级心法**：约 528 条，情况好一些但依然混杂了不少偏身法/拳脚感的
  命名（比如"疾风功""轻云功"这种听起来像轻功身法的名字）。

天级（4条：混沌圣诀/九转魂功/万灵归元术/乾坤造化功）和地级（16条：天罡诀/
归元诀/玄冥典/白虎经/鲲鹏典等）这两个品阶本来就是手写的，命名水准已经
符合要求，**不需要动**。

## 心法应该是什么

心法是以"意识与灵气运转规则"为核心的修炼系统，用来规定修士如何吸收、
循环并强化自身能量——不是一个具体的招式动作，而是一套内在的运行法则。

## 命名规则

每个心法名字由三部分组成：

1. **意境词**：随品阶从具象过渡到抽象。
   - 黄级：具体的五行属性/自然意象词，比如"炎""寒""岩""风""潮"
     "雷"这类贴合该条目 `element` 属性的字，或者"元""息""脉""气"
     这类基础修炼概念词。
   - 玄级：往上一层的抽象词，比如"玄""罡""灵""真""道"这类。
   - （地/天级已经手写好了，不用你管，仅供参考更高层次该有的味道：
     "混沌""九转""万灵""乾坤"这种宇宙法则级的词。）
2. **运行机制词**：必须是描述"灵气如何在体内运转/转化"的动词，比如
   "凝""转""归""化""引""摄""循""朝""聚""炼""养""固"，**不能用
   "甩""踢""劈""扫""踏""挂""抛""掘""拖""铲""撕""扣""挖"这类
   肢体动作动词**——这是最重要的一条硬规则，是这次要修的核心问题。
3. **类型后缀**：心法/心经/真诀/心诀/真经/内经 这几个词里选一个。

举例：
- 黄级：炎息诀、寒脉经、岩固功、风引心法
- 玄级：玄罡归元诀、灵真凝气经、道息真经

## 这次要做的事

1. 已经把 `category == "心法"` 且 `tier` 是"黄级"或"玄级"的条目分别导出
   成了两个文件：`心法黄级_待改名.json`（13031条）、`心法玄级_待改名.json`
   （528条），把这两个文件的内容发给你（黄级数量大，可能需要分批发送）。
2. 只重新生成 `name` 字段，其它字段（`tier`/`element`/`category`/
   `creator`/`holder`/`prevalence`/`effect` 等）原样保留，一个字都不
   能改——只是换个符合规则的名字。
3. 新名字要贴合该条目原有的 `element` 属性（意境词从这个属性延伸，
   比如 `element` 是"火"就该往"炎/焰/阳"这类词走，不能文不对题）。
4. 同一品阶内不能有重复的名字。
5. 天级/地级已经写好的20条不用碰，也不用发给你。

## 输出格式

按发给你的条目顺序，输出一个同样长度的 JSON 数组，每项只有 `name` 字段
（比如 `["炎息诀", "寒脉经", ...]`），顺序要跟我发的条目一一对应，方便
我原样替换回原数据文件，不需要把其它字段也发回来。

## 校验要求

交付后我会核对：
1. 数组长度跟发给你的条目数一致，不多不少。
2. 每一批（黄级/玄级各自）内部没有重复名字。
3. 抽查一批名字里"运行机制词"部分，不能出现"甩/踢/劈/扫/踏/挂/抛/掘/
   拖/铲/撕/扣/挖"这类肢体动作字。
