# 使用说明 —— QQ 群跑团助手

> 这份文档写给**在群里实际玩跑团的人**看（团长、玩家），不涉及安装和代码。
> 安装方法、依赖、数据存储的技术细节请看同目录下的 `README.md`。

## 这个插件能干什么

装上之后，群里可以直接用指令掷骰子、建角色卡、管团长权限，还能让 AI 帮忙
生成 NPC/场景描写；群里的发言也会自动存成团务日志，方便团长回看。

所有指令前面的 `/` 是机器人默认的唤醒前缀，如果你们机器人改过前缀，就把
下面例子里的 `/` 换成你们自己的前缀。

## 怎么用（按角色分）

### 我是团长，第一次开团怎么弄

1. 让 AstrBot 管理员（配置里 `admins_id` 里的人）在群里发：
   ```
   /gm add 你的QQ号
   ```
   把你设为本群团长。
2. 玩家们各自发 `/pc new 角色名` 建卡，再用 `/pc set` 填属性。
3. 正常聊天开团即可，插件会自动把大家的发言记进团务日志，不用你操心。

### 我是玩家，怎么建角色卡

```
玩家: /pc new 阿尔萨斯
机器人: ✅ 角色卡「阿尔萨斯」创建成功！
玩家: /pc set 力量 14
机器人: ✅ 已把自己的「力量」设置为 14
玩家: /pc show
机器人: 📜 角色卡：阿尔萨斯
        👤 玩家QQ：xxxxxx
        ━━━━━━━━━━━━━━
        力量：14
        ━━━━━━━━━━━━━━
        创建于：2026-07-03 21:05:33
```

一个人在一个群里只能有一张卡，想重建要先 `/pc del` 删掉旧的。

### 掷骰子

```
/r 1d20        掷一个20面骰
/r 2d6+3       掷两个6面骰再加3（/roll 也可以用）
/r d100        百分骰，前面的骰子数可以省略
```

### 让 AI 生成 NPC / 场景描写

```
玩家: /npc 一个独眼的兽人铁匠
机器人: 🎭 正在酝酿剧情，请稍候……
机器人: 🎭 （这里是 AI 生成的一段 150~250 字的描写）
```

这个功能需要 AstrBot 管理面板里已经配置并启用了一个 LLM（比如本地 Ollama）。
如果一直提示失败，找 AstrBot 管理员确认 LLM 是不是配好了、开着。

### 团长管理

```
/gm add QQ号   任命团长（仅 AstrBot 管理员或现有团长可用）
/gm del QQ号   撤销团长
/gm list       查看本群团长名单
```

### 忘记指令了

群里发 `/trpg`，机器人会把所有指令列一遍。

### 嫌每次都要打 “/” 太麻烦？开启 TRPG 模式

**仅团长/AstrBot 管理员**可以给本群开启「TRPG 模式」：

```
/gm add 你的QQ号     先确认自己是团长（如果还不是的话）
/trpg on            开启本群的 TRPG 模式
```

开启之后，本群所有指令都可以**不带 `/`**，也可以**用数字 `1` 代替 `/`**，
效果完全一样：

```
r 1d20          等价于  /r 1d20
1r 1d20         等价于  /r 1d20
pc show         等价于  /pc show
1npc 一个神秘的商人   等价于  /npc 一个神秘的商人
```

不想用了就发 `/trpg off` 关闭，恢复成只认 `/` 前缀。

> ⚠️ **注意**：TRPG 模式开着的时候，只要一句话的**第一个词**恰好是
> `r`、`roll`、`pc`、`gm`、`npc`、`trpg` 这几个词之一，就会被当成指令处理
> （哪怕后面跟着的不是有效参数，也会回一条"格式不对"的提示）。平时闲聊一般
> 不会撞上，但如果发现有人说话被误判成了指令，建议团长把这个模式关掉，
> 或者提醒大家发这几个词开头的话之前空一格再打字。
>
> 无论 TRPG 模式开没开，用标准的 `/r`、`/pc` 这种带 `/` 的写法**永远都能用**，
> 这个模式只是多加了两种更省事的写法，不影响原来的用法。

### 团长带新团怎么开（引导建团流程）

如果你嫌一个个教玩家怎么用 `/pc new`、`/pc set` 太麻烦，可以用这套"引导建团"
流程，让机器人带着玩家自己建卡：

```
团长: /trpg invite 12345678 87654321
机器人: 📣 团长邀请以下玩家加入本团：12345678、87654321
        请每位被邀请的玩家在群里直接回复：
        1 —— 完全随机建卡（自动帮你随机好所有属性）
        2 —— 引导式建卡（一步步问你，自己填属性）

玩家A: 1
机器人: ✏️ 请回复你的角色名（不要带空格）：
玩家A: 阿尔萨斯
机器人: 🎲 角色「阿尔萨斯」建好啦！属性已随机生成：
        力量：65  敏捷：70  智力：55  体质：60  魅力：45  运气：50

玩家B: 2
机器人: ✏️ 请回复你的角色名（不要带空格）：
玩家B: 米拉
机器人: ✏️ 请输入「力量」的数值（整数）：
玩家B: 14
机器人: ✏️ 请输入「敏捷」的数值（整数）：
玩家B: 16
...（依次问完 智力/体质/魅力/运气 六项）
机器人: ✅ 角色「米拉」建好啦！
        力量：14  敏捷：16  智力：...

机器人: 🎉 所有受邀玩家都完成建卡啦！团长可以发 /trpg start 正式开始跑团。
团长: /trpg start
机器人: ✅ 跑团正式开始！祝大家玩得开心 🎲
```

要点：
- `/trpg invite QQ号1 QQ号2 ...`：仅团长/管理员可用，可以带 `@` 也可以直接
  写 QQ 号，空格隔开多个人。
- 被邀请的玩家在群里**直接回复数字** `1` 或 `2` 即可，不用带任何前缀。
- 引导式建卡时如果输入的不是整数，机器人会重新问同一项，不会跳过。
- `/trpg start` 不要求所有人都建完卡——团长随时可以强制开始，没建完的玩家
  之后自己用 `/pc set` 补属性也可以。
- 开团后（`/trpg start` 之后），**受邀玩家**在群里说的每一句话，机器人都会
  用 AI 判断一下是角色在游戏里的行动/发言，还是纯聊天/吐槽。判断为游戏内
  的话，机器人会自动接一段剧情叙述（前面带 🎭）；纯聊天不会打扰。
- 想结束这一团、准备开新团邀请新玩家，团长发 `/trpg end`：只重置邀请/建卡
  的进度，**角色卡、团长名单、TRPG 模式开关都不受影响**，不用担心卡被删。

## 完整指令表

| 指令 | 谁能用 | 说明 |
| --- | --- | --- |
| `/r 2d6+3` / `/roll 1d20` | 所有人 | 掷骰子，支持 `NdM`、`NdM+K`、`NdM-K`、`d100` |
| `/pc new 角色名` | 所有人 | 创建自己的角色卡（每人每群一张） |
| `/pc show [QQ号]` | 所有人 | 查看自己或指定人的角色卡 |
| `/pc set 属性 数值` | 所有人（改自己） | 修改自己角色卡属性，如 `/pc set 力量 14` |
| `/pc set 属性 数值 QQ号` | 仅团长 | 修改别人的角色卡 |
| `/pc del [QQ号]` | 所有人（删自己）/ 团长（删别人） | 删除角色卡 |
| `/gm add QQ号` | 管理员/团长 | 任命团长 |
| `/gm del QQ号` | 管理员/团长 | 撤销团长 |
| `/gm list` | 所有人 | 查看本群团长名单 |
| `/npc 描述` | 所有人 | AI 生成 NPC / 场景叙事 |
| `/trpg` | 所有人 | 显示帮助 |
| `/trpg on` / `/trpg off` | 管理员/团长 | 开启/关闭本群 TRPG 模式（无前缀指令） |
| `/trpg invite QQ号...` | 管理员/团长 | 邀请玩家加入本团，走建卡向导 |
| `/trpg start` | 管理员/团长 | 正式开始跑团（未建完卡也能强制开始） |
| `/trpg end` | 管理员/团长 | 结束本团，重置邀请状态（不影响角色卡/团长/TRPG模式） |

## 常见问题

- **Q: 为什么 `/npc` 一直提示生成失败？**
  A: 这个功能依赖 AstrBot 里启用的 LLM 提供商，找管理员确认有没有配置并
  启用（比如本地 Ollama 是否在运行）。
- **Q: 我建错角色卡名字了怎么办？**
  A: 目前没有改名指令，先 `/pc del` 删掉，再用正确的名字 `/pc new` 重建。
- **Q: 角色名/属性名能带空格吗？**
  A: 不能，指令是按空格切分参数的，角色名和属性名请用不带空格的词。
- **Q: 团务日志我能自己看吗？**
  A: 目前没有查询指令，日志是纯文本文件，需要请 AstrBot 管理员帮忙从
  服务器上取（路径见 `README.md` 的数据存储说明）。
- **Q: 开团后为什么有的话机器人会自动接一段剧情，有的不会？**
  A: 开团进行中（`/trpg start` 之后），受邀玩家说的每句话都会被 AI 判断一次
  是"游戏内行动"还是"场外聊天"。判断成游戏内的，机器人会自动接一段剧情
  （前面带 🎭）；判断成场外聊天的，机器人不会回应，但还是会正常记进团务
  日志。这个判断不是关键词匹配，是每条消息都问一次 AI，AI 偶尔判断不准
  也是正常的。
- **Q: 邀请玩家之后，玩家一直没回复 1/2 怎么办？**
  A: 目前没有超时/催促机制，玩家什么时候回复都行，团长也可以随时
  `/trpg start` 强制开始，不用等所有人建完卡。

## 使用限制

- 角色卡、团长、团务日志功能都只能在**群聊**里用，私聊没有效果。
- 团务日志只记录群成员发的**文字**消息，纯图片/表情和机器人自己的回复不会被记录。
- 开团进行中（`/trpg start` 之后），受邀玩家发的**每一条**消息都会额外触发
  一次 AI 判断请求。如果用的是本地部署的模型（比如 Ollama），长时间跑团
  可能会感觉到延迟，或者增加本地设备的负担；目前没有单独关闭"AI 判定"
  这一项的开关，如果觉得吵可以先 `/trpg end` 结束本团。
- 引导建卡时角色名、属性数值都是单条消息回复，暂不支持中途改主意换建卡
  方式（1/2 选完就定了）；建完卡之后仍然可以用 `/pc set` 手动调整属性。
