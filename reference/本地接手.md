# 青玄宗五人跑团 · 本地接手

**当前可以接着做外门设定讨论。下一题是“一个新弟子刚进外门，谁领他开始修《青玄真经》入门总纲，他怎样获得第一次基础传授？”** 先确定人与人的关系，再讨论法术怎么学。五人完整章节和真实五人试玩仍待完成。

先看[青玄宗外门设定](../world/青玄宗外门设定.md)，了解已确认的功法堂、院落和择徒安排。讨论教导时用[研究与取舍](外门生活研究与取舍.md)比较作品实例；查程序、存档和旧文件时用[迁移清单](云端迁移清单.md)。

## 本轮目标与验收

用户选择一名主持人带五名玩家，共用本地辅助工具。章节从大比前的外门生活开始，各人决定是否参赛，经历切磋、大比或场外事务，走到有反馈和后续去向的结尾。用户要求大比以外也有独立成立的故事。全界人口、高阶修士数量、完整经济和宗门兴衰留待后续。

| 要检验的事 | 旧评估提出的交付方式 | 当前状态 |
| --- | --- | --- |
| 五个人各有事可做 | 主持资料包含同门的动机、可追踪的线索、事务变化和失败后果。分头所得能在合流后发挥作用，未参赛者在赛中仍能行动。 | 住处方向已认可，人物和独立剧情待定。5–6 处地点、三件可交错的事务等数量是估算。 |
| 选择确实有代价 | 工具能查看角色状态、比较修炼或恢复所需的时间与资源，战后保留伤势、物资和人情后果。 | 原云助手报告有隔离原型；本机缺 v28 源码。 |
| 整团能暂停并继续 | 建议用五张独立角色卡、共同时间、个人与公共资源分账、整团存读档；主持人能裁定菜单外行动。 | 五人流程、数据一致性和赛后分支仍待实现或用原件核对。 |
| 章节可从头跑到结尾 | 用新试玩档由一名主持人和五名玩家实际跑一场，记录各人参与、参赛与场外选择、暂停续接及结尾反馈。 | 尚无真实五人试玩。 |

早期仓库以五区开局或机器人配置为背景。[11 月 3 日交接分支](https://github.com/yqyjswj2001-cell/TRPG/tree/52b30f1225ff21c397d243bf84b6f88a0268eaf4)保留五洲、东荒七州、三圣九宗、仙舟接引至问道长阶入外门的阶段记录，当时尚未确定首宗名，游玩人数记为 3–5。随后逐项确认的青玄宗和本轮五人目标见本次设定。旧地理、开局槽位、静态数表与实体 ID 的映射须单独讨论。两份旧文可在本地用 `git ls-tree --name-only origin/setting/wuzhou-sanzong-20261103-handoff:world` 定位。
