# 资料来源与署名

仓库目前没有统一 LICENSE。本次维护不代替权利人决定转载、修改或商用许可，也不宣称仓库中的所有旧条目都拥有可对外再许可的权利。

新增或引用资料时，在条目备注或关联 PR 中记录：

| 字段 | 填写内容 |
| --- | --- |
| 来源 | 自行创作、AI 辅助整理，或原作者及原文链接 |
| 贡献 | 由谁补充、修改了哪些内容；Git 提交与 PR 可作为记录 |
| 授权情况 | 已知的许可证或授权依据；不清楚就写待核实 |

AI 辅助生成不能代替来源核实。第三方小说、游戏和规则书的段落、图片等，不因可在网上查看就可整批复制；来源或授权不明时先讨论处理方式。

正式对外授权前，维护者需确定：哪些内容有权授权、采用何种许可证、署名方式、转载与商用范围，以及第三方资料的排除项。决定后再统一发布 LICENSE 并同步本说明。

参考：[GitHub 关于许可证的说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)。
