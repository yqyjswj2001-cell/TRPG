# 采用清单

本页用于汇总《东荒》TRPG 的规则模块与内容资料，并记录各团的规则组合与调整。

| 资料目录 | 内容定位 | 使用说明 |
| --- | --- | --- |
| `world/` | 世界观与玩法规则 | 世界运行、开局、战斗、经济、死亡与重生 |
| `rules/` | 结构化设定与数值表 | 灵根、修炼、天赋、NPC、天气和事件参数 |
| `data/` | 世界内容资料 | 地点、势力、人物、功法、物品、生灵与历史 |
| `reference/lexicons/` 与命名资料 | 创作参考 | 名称词表、事件模板及内容创作辅助 |

## 团务规则记录

确定某个团使用的规则时，可在本页新增记录，注明团名或设定版本、采用的文件和章节、调整内容、确认日期与关联 PR。

如果不同版本对同一机制有不同规定，先列明差异与适用范围，再决定如何处理。已开团的规则变动应说明对现有角色和剧情的影响。
