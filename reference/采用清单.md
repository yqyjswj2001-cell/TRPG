# 采用清单

本清单区分“仓库里有的资料”和“某个团真正采用的规则”。截至 2026-10-16，本次仓库整理没有确认任何新团的完整规则集，也没有迁移旧角色或旧存档。

| 资料 | 当前状态 | 使用方式 |
| --- | --- | --- |
| `world/` 世界与玩法原文 | 历史参考 | 采用前确认具体章节及不沿用的例外 |
| `rules/` 静态设定表 | 历史参考 | 核对来源、单位、范围和正文，不默认冻结数值 |
| `data/` 内容资料 | 资料库 | 查阅、选用；样例与生成条目不自动成为当前世界事实 |
| `reference/lexicons/` 与命名资料 | 创作参考 | 用于构思，不保证每个条目均已通过世界观审查 |

新增一项实际采用记录时，填写：适用团或设定版本、明确文件与章节、采用内容、排除内容、确认日期、关联 PR。没有确认依据就保持提案或待讨论。

版本间存在冲突时先列出差异，不直接覆盖旧事实；已开团的规则变更须说明对已有角色和剧情的影响，并由参与者确认处理方式。
